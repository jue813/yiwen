# 译问 · 西译校园通知智能解读平台

> 把官方红头文件，翻译成学生一看就懂、照着就能做的行动。

西安翻译学院校园信息精读平台：通知、竞赛、活动、社团、学分、问答，一站聚合，逐条讲清。

## 核心功能

- **钟面导航**：通知 / 竞赛 / 活动 / 社团 / 学分 / 问答，六个方向挂在一个钟面上
- **原文 → 批注**：红头文件原文（仿宋 + 印章）对照四要素解读（谁 / 做什么 / 什么时候 / 注意什么）
- **通知精读**：12 份真实校内文件，点开可查看官方 PDF 原件
- **竞赛聚合**：报名时间、截止倒计时、官方网站直达链接
- **学分进度**：素质拓展 8 学分四模块完成度 + 成果折算表
- **社团实拍**、**西译四时**、**问答速查**、**校园地图**、**反馈建议**

## 设计母题

「钟塔 = 校园的时间坐标」——冷雾蓝纸底、墨色正文、朱红批注、赤金尖顶。
字体三层语义：宋体（标题）/ 仿宋（红头原文）/ 黑体（正文）。

## 技术栈

纯原生 HTML / CSS / JavaScript，无框架、无后端，移动端响应式。

## 团队

西安翻译学院 · 电子信息科学与技术 · 5 人团队

## 部署

静态站点，可直接部署到 GitHub Pages / Gitee Pages 或任意静态托管。
打开 `index.html` 即可本地预览。
